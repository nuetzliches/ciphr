# ADR-10 — Default port `:4400`

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-08-18 |
| **Affects** | Default configuration, deployment |

## Context

A default port is a small decision that becomes expensive to change once it appears in firewall
rules, proxy configuration, health checks, and other people's notes.

## Decision

The API listens on `:4400` by default.

## Rationale

It avoids the ports most likely to collide or to confuse in this problem space:

- `:8200` — Vault and OpenBao. If ciphr and OpenBao ever run side by side, during a migration in
  either direction, no operator should have to guess which one answered.
- `:9090` — Prometheus.
- `:8080` — the default of nearly everything else.

There is no deeper reason than that, and none is needed.

## Consequences

- `:4400` appears in the default configuration, the container image, the health checks, and the
  examples. Changing it later means touching all of them, which is the reason to settle it now.

## Rejected alternatives

`:8200` — familiar to anyone who has used Vault, and that familiarity is exactly the hazard.
